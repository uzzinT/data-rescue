# 데이터 구조대 (Data Rescue)

통합과학2 **Ⅲ-1-02. 과학 기술 사회에서 빅데이터 활용** 수업용 2D 웹 게임입니다.
학생은 데이터 드론을 조종해 재난(집중호우·미세먼지·폭염) 속에서 관측 데이터를 모으고, 검증·분석한 뒤 위험 구역의 동료 대원에게 경보를 보내 구출합니다.

## 바로 해 보기

**학생용 주소: https://uzzint.github.io/data-rescue/** (1차 초안: https://uzzint.github.io/data-rescue/v1/)

| 버전 | 파일 | 특징 |
|---|---|---|
| **2D 액션판 (현재 버전)** | [`index.html`](index.html) | AI 파트너 대사, 재난 피하기, AI 예측, 데이터 양 슬라이더, 윤리 선택 |
| 1차 초안 | [`v1/index.html`](v1/index.html) | 지도에서 데이터 수집 → 표 정제 → 경보 (액션 요소 적음) |

- 설치할 것 없이 `index.html`을 브라우저(크롬·엣지)로 열면 됩니다.
- 인터넷이 연결되어 있으면 Google Fonts 글꼴이 적용되고, 없으면 기본 글꼴로 동작합니다.
- 한 판(임무 3개 + 분석)은 약 15~20분입니다.

## 게임 흐름

1. **수집 (액션)**: 관측소 8곳에서 데이터 내려받기. 드론이 움직이는 동안에도 데이터 행이 쌓임
   - 위험(낙뢰 / 보이지 않는 미세먼지 / 햇볕 과열)은 **AI 예측이 켜져야** 미리 보임 (데이터 150행 이상)
   - 보라색 **가짜 뉴스 봇**: 닿으면 소문이 데이터에 섞이고 AI 정확도 하락, 돌진으로 부수기
   - 빨간 자물쇠 **개인정보 자료**: "+300행"의 유혹, 수집 여부를 학생이 판단
   - 드론 3대. 모두 잃으면 임무 1부터 다시
2. **분석**: 출처별 데이터 검증 → 구역별 그래프(측정값 점·평균·오차 범위) → 데이터 양 슬라이더와 "다시 뽑기"로 표본 크기 체험 → 질문 2개
3. **경보**: 경보 종류와 구역을 골라 발송 → 대원별 결과, 별점(기준 3개), 개념 정리, 생각해 보기(학생 코멘트 입력)
4. **마지막 선택**: 주민 위치 데이터 활용에 대한 윤리 선택 → 최종 보고서(코멘트 모음 복사 가능)

## 조작법

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (휴대폰: 화면 끌기) |
| Space / Shift | 돌진 (위험 피하기, 봇 부수기) |
| E (누르고 있기) | 보호막 (피해 75% 감소, 느려짐) |
| H | 조작법 보기 · 일시정지 |

## 수업 내용 바꾸기

`index.html` 아래쪽 `<script>`의 **`MISSIONS`**(임무별 데이터·기준·대사·질문·개념·생각해 보기)와 **`STORY`**(첫 대사·마지막 선택)만 고치면 됩니다. 자세한 규칙은 [`CLAUDE.md`](CLAUDE.md), 수업 설계는 [`docs/`](docs/)를 보세요.

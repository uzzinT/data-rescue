# 참고 게임 분석: 크로노스 프로토콜

- 과거 편: https://moonclipse-t.github.io/big-data_past (1차시 · 고생대의 바다)
- 미래 편: https://moonclipse-t.github.io/big-data_future (2차시 · 바이러스 X)
- 3D(three.js) 게임. 3D 모델은 Sketchfab, 환경은 Poly Haven, 음악은 ElevenLabs.

이 문서는 플레이하고 구조를 살펴본 뒤 정리한 요약입니다. 코드·문구·에셋은 가져오지 않았습니다.

## 구조

| 요소 | 과거 편 | 미래 편 |
|---|---|---|
| 이야기 | 타임머신 사고로 고생대 바다에 떨어짐, 아기 삼엽충이 됨 | 2187년 바이러스 환자의 몸속에 나노봇으로 들어감 |
| AI 파트너 | ARIA (대사창, 타자 효과) | ARIA |
| 액션 | 먹이 먹고 성장, 포식자의 "!" 공격 예고를 돌진으로 피하기, 몸 말기 방어 | 바이러스 레이저, 면역 세포 피하기, 위장막 |
| 데이터 | 몸의 센서가 수심·수온·산소 등을 "행"으로 계속 기록, 관측 부표 회수 | 혈관·심장·뇌에서 샘플 채취, 데이터 노드 수리 |
| AI 예측 | 데이터가 쌓이면 먹이 많은 곳·포식자 위험 예측, 정확도 % | 비슷한 구조 |
| 분석 화면 | 데이터 지도 비교(데이터 양 슬라이더), 고장 부표 값 빼기, 막대·꺾은선 그래프, 오차 범위, 질문 | 원인·위험 환자·치료제 설계 |
| 마무리 | 귀환 좌표 조각 모으기 | 유전체 데이터 공유에 대한 윤리 투표 |

## 데이터 구조대에 가져온 "느낌"

- AI 파트너와의 대사로 시작하는 이야기 구성
- 위험을 피하는 액션 + 체력
- 내 드론이 움직일수록 데이터 행이 쌓이는 감각 (화면의 데이터 로그)
- 데이터가 많을수록 AI 예측 정확도가 오르고, 위험을 미리 알려 줌
- 분석 화면의 데이터 양 슬라이더, 이상값 걸러 내기, 질문과 피드백
- 마지막 개인정보 윤리 선택

## 다르게 한 것

- 2D 한 화면, 더 간단한 조작 (수업 시간 안에 끝나도록)
- 빅데이터 내용(데이터 → 정보 → 지식, 검증, 경보 판단, 장점·문제점)의 비중을 게임 플레이 안에서 크게 유지
- 외부 3D 모델·에셋 없이 캔버스로 그림

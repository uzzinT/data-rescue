# 수업 설계

## 교육과정 연계

- 과목: 통합과학2 (2022 개정, 비상교육)
- 단원: Ⅲ. 과학과 미래 사회 > 1. 과학 기술의 활용 > **02. 과학 기술 사회에서 빅데이터 활용**
- 교과서 120~125쪽 / 지도서 242~249쪽 (1~2차시)

### 지도서의 지도 목표 (요약)

1. 일상생활에서 실시간으로 생활 데이터를 측정할 수 있다.
2. 빅데이터를 사용하는 사례를 조사해 빅데이터 활용의 장점과 문제점을 추론할 수 있다.

### 지도서 내용 중 게임에 반영한 것

| 지도서 내용 | 게임 속 반영 |
|---|---|
| 데이터(원자료·가공된 데이터) → 정보 → 지식 (강수량 → 지역별 최대 강수량 → 도시 침수 예보) | 관측값 수집 → 구역별 평균 그래프 → 경보 발령, 결과 화면의 3단 정리 |
| 국가가 제공하는 실시간 생활 데이터 (국립해양조사원, 에어코리아, 서울 열린데이터 광장) | 임무별 데이터 출처 설명, 미세먼지 임무의 개념 정리 |
| 디지털 탐구 도구로 미세먼지 측정 (교실 35, 운동장 50, 체육관 40 µg/m³ 예시) | 미세먼지 임무 개념 정리, 생각해 보기 질문 |
| 좋은 수업을 위한 제안: 직접 측정한 값과 에어코리아 값의 차이 토의 | 미세먼지 임무 "생각해 보기" |
| 스마트워치로 심박수·수면 패턴 측정 | 폭염 임무의 개인정보 자료(스마트워치 건강 기록) |
| 정형 데이터와 비정형 데이터 | 미세먼지 임무의 CCTV 영상(비정형) vs 측정기 수치(정형) |
| 빅데이터의 장점과 문제점 (사생활 침해, 검증되지 못한 데이터, 지나친 의존) | 개인정보 선택, 가짜 뉴스 봇, 장비 오류값 정제, 최종 보고서 |
| 과학 실험: 데이터 양이 많을수록 신뢰도 증가, 적으면 편향 | 분석 화면의 데이터 양 슬라이더와 "다시 뽑기", AI 정확도 |
| 기상 관측, 유전체 분석, 신약 개발, 교통 | 개념 정리와 최종 보고서 모둠 토의 |
| 날씨마루(기상청) 등 기상 빅데이터 서비스 | 호우 임무 개념 정리 (기상 빅데이터로 재해 예방) |

## 임무 구성

| 임무 | 데이터 | 경보 기준 | 위험 구역 | 걸러 낼 자료 |
|---|---|---|---|---|
| 1. 집중호우 | 3시간 누적 강수량 (mm) | 90 mm 이상 → 호우 경보 | 산마루동, 강변동 | 산마루동-2 센서 오류값 -999, SNS 소문, 휴대전화 위치 기록 |
| 2. 미세먼지 | 최근 2시간 평균 PM10 (µg/m³) | 150 이상 → 미세먼지 주의보 | 강변동, 바다동 | 산마루동-2 이상값 9999, 단톡방 소문, CCTV 원본 영상 |
| 3. 폭염 | 오늘 최고 체감온도 (℃) | 35 ℃ 이상 → 폭염 경보 | 하늘동 (도시 열섬) | 산마루동-2 결측값, 블로그 소문, 스마트워치 건강 기록 |

## 수업 운영안 (예시, 1차시 50분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 5분 | "재난 문자는 어떻게 정해질까?" 질문, 데이터 → 정보 → 지식 소개 |
| 게임 | 25분 | 개인 또는 2인 1조로 임무 1~3 플레이 |
| 정리 | 15분 | 최종 보고서의 "나의 생각 모음" 복사해 제출, 장점·문제점 정리 |
| 마무리 | 5분 | 모둠 토의 질문 1개 발표, 다음 차시(사례 조사) 예고 |

2차시로 늘릴 때는 2차시에 교과서 탐구(빅데이터 활용 사례 조사: 과학 실험·유전체 분석·신약 개발)를 직소 모형으로 운영하고, 게임의 최종 보고서를 근거 자료로 씁니다.

## 평가 연계 아이디어

- 지도서의 보고서 평가 기준(사례를 옳게 조사, 장점과 문제점을 옳게 정리)에 "나의 생각 모음"을 근거 자료로 활용.
- 별점 ③(데이터 윤리)은 태도 관찰 자료로 쓸 수 있으나 점수화는 권하지 않음 (선택을 체험하는 것이 목적).

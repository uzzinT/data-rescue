# 피드백 기록

교사 요청과 그에 따른 수정 내역입니다. 새 요청이 생기면 아래에 이어서 적어 주세요.

## v1 — 1차 초안 (2026-10-18)

요청: 통합과학2 빅데이터 단원을 지도서를 참고해 2D 게임 웹앱으로. 데이터를 수집하고, 가공하고, 동료에게 경보를 보내 구출하는 게임.

만든 것 (`v1/index.html`)
- 가람시 지도(4개 구역)에서 관측 장비 8대의 데이터 수집, 출처 불명 자료·개인정보 자료 판단
- 원자료 표에서 오류값·결측값·함정 자료 제외 → 가공 방법 선택 → 구역별 막대그래프
- 경보 종류·구역 선택 → 대원별 결과, 개념 정리, 생각해 보기, 최종 보고서
- 임무: 집중호우, 미세먼지, 폭염

## v2 — 2D 액션판 (2026-10-18)

요청: 「크로노스 프로토콜」(과거 편·미래 편)을 플레이해 보고, 그 느낌으로 2D로 더 간단하게. 빅데이터 내용 비중은 v1처럼 유지하고 게임 플레이 느낌만 바꾸기. 필요하면 Blender, Poly Haven, Sketchfab 사용.

만든 것 (`index.html`)
- AI 파트너 "나래"와의 대사, 대원 이름 입력
- 재난 피하기(낙뢰·먼지 구름·폭염), 돌진, 보호막, 체력
- 드론이 움직이는 동안 데이터 "행"이 쌓임, 실시간 데이터 로그
- 데이터가 쌓이면 AI 예측 정확도 상승
- 가짜 뉴스 봇(닿으면 소문이 섞여 AI 정확도 하락), 개인정보 "+300행" 유혹
- 분석: 출처별 검증, 데이터 양 슬라이더와 오차 범위, 질문, 경보
- 마지막 윤리 선택(주민 위치 데이터 활용)
- 외부 에셋 없이 캔버스로 직접 그림 (아티팩트 보안 정책상 외부 이미지·모델 불가, Sketchfab은 계정 로그인 필요, Blender 미설치)

## v2.1 — 수업 피드백 반영 (2026-10-19)

| # | 요청 | 수정 |
|---|---|---|
| 1 | 검증 완료를 눌러도 확인할 묶음이 노란색으로 안 보임 | 처음 틀렸을 때부터 진한 노란색 + "확인 필요" 표시 (원래는 두 번째부터, 색도 너무 옅었음) |
| 2 | 데이터 양에 따라 편차가 크게 보이게 | 개별 측정값 흔들림 확대, 측정값 점 표시, 세로축 고정, 슬라이더 1%까지, "다시 뽑기" 버튼, 질문 문구 수정 |
| 3 | 낙뢰가 빨갛게 미리 보여 AI 예측이 필요 없음 / 미세먼지에 낙뢰가 맞나 | 빨간 예고 제거, AI가 예측한 위험만 파란 원으로. 미세먼지 임무에서 낙뢰 제거, 대신 미세먼지가 처음엔 흐릿하고 AI가 켜지면 농도 지도로 보임 |
| 4 | 플레이 중에도 조작키 확인 | "조작법 ?" 버튼, H 키(일시정지), 게임 화면 아래 조작키 안내 줄 |
| 5 | 제대로 해도 별이 2개만 나옴 | 원인: 세 번째 별이 "가짜 뉴스 봇에 한 번도 안 닿음"까지 요구했음. 조건에서 빼고, 별 기준 3개를 결과 화면에 표시 |
| 6 | 생각해 보기에 학생 코멘트 / 강수량·미세먼지 질문이 비슷함 | 코멘트 입력란 추가, 최종 보고서에 모아 보기와 복사 버튼. 미세먼지 질문을 "교실 측정값 vs 에어코리아 값" 비교로 교체 |
| 7 | 각 임무에서 게임 지도 다시 보기 | 분석 화면과 경보 단계에 지도(드론 경로, 관측소 수집 여부, 대원 위치) |
| 8 | 드론 목숨 3개, 모두 잃으면 처음 임무로 | 구현 (부활 시 2.5초 무적, 모은 데이터 유지) |
| 9 | 체력 0인데 계속 플레이됨 | 원인: 봇에 닿을 때 체력을 따로 깎고 0 확인을 안 함. 모든 피해를 `hurt()`로 모으고 매 프레임 확인 |
| 10 | 알아서 점검·수정 | 대사 건너뛰기 버튼, 다시 시작 시 첫 이야기 생략, 학생 입력 이스케이프, 판정이 흔들리지 않게 임무별 측정값 조정 |

## v2.2 — 수업 피드백 반영 (2026-10-19)

| # | 요청 | 수정 |
|---|---|---|
| 1 | 데이터 양을 달리하면 결괏값이 달라질 수 있게 | 그래프 아래 "이 데이터로 내린 판단" 추가, 고른 데이터 양의 결과가 경보 단계로 넘어감. 기준에 가까운 구역 값을 조정해 데이터가 적으면 판단이 갈리게 함 |
| 2 | 드론이 너무 오래 버팀 / AI 예측은 자료가 많을수록 높게, 최대 70% / 낙뢰는 강수량에서만 | 피해량 상향(낙뢰 13→20, 봇 6→10, 미세먼지 11→17/초, 햇볕 3.6→6/초). AI 정확도 30%→최대 70%. 폭염의 아스팔트 열기 제거, 대신 AI가 가까운 그늘을 화살표로 안내 |
| 3 | 미세먼지 피해가 눈에 띄게 | 화면이 탁해지는 효과, 붉은 피해 숫자, "미세먼지 흡입 중! 체력 −17/초" 경고 |
| 4 | 가짜 뉴스 봇 수만큼 내용도 추가 | 임무별 소문 6개, 봇마다 다른 소문이 들어가고 검증 표에 모두 나열 |
| 5 | 분석 데이터 양 기본값을 중간으로 | 기본 50% |
| 6 | 미세먼지·폭염 생각해 보기 예시 문장이 맞지 않음 | 임무별 예시 문장으로 교체 (원래는 세 임무 모두 "데이터를 그대로 믿으면 …") |
| 7 | 보고서 이미지 저장 / 처음 화면 가기 전 확인 | "보고서를 이미지로 저장" 버튼, "정말 처음 화면으로 가시겠습니까?" 확인 팝업 |
